# 常驻资料与记事本计划

本计划作为当前代码的功能契约与后续验收依据。聊天示例分区随 v0.8.0 提供，功能与迁移验证尚未运行。

## 内容和权限

| 分区或资料 | 保存内容 | 加载方式 | 修改权限 |
| --- | --- | --- | --- |
| 性格和人设 persona | 身份、性格、人设要求 | 每轮完整加载 | 用户手动修改 |
| 回复偏好 output_preferences | 输出风格、格式、表达要求 | 每轮完整加载 | 用户手动修改 |
| 聊天示例 chat_examples | 聊天情境与期望回复，示范语气及文字、表情包、语音的使用 | 每轮完整加载 | 用户手动修改 |
| 昵称 nicknames | 昵称、别名和称呼对应关系，字符串列表 | 每轮完整加载 | 用户编辑，机器人通过昵称工具增删 |
| 自我认知 other | 相处中形成的认识、习惯和需要记住的变化 | 每轮完整加载 | 用户编辑，机器人通过自我认知工具维护 |
| 记事本目录 | 每页的标识、名称、描述 | 正式回复每轮完整加载 | 随页面变化同步 |
| 记事本正文 | 黑话、详细事件、关系、待办和流程 | 通过工具按需读取 | 用户和机器人维护 |
| 记忆记录与原文 | 五分区快照、结果和来源 | 用户打开管理页时读取 | 插件留存 |

保存层按写入来源执行精确字段限制：自我认知工具只允许 other 变化，昵称工具只允许 nicknames 变化；其他分区、标题和外部附注逐字保持。管理页和 AstrBot 原人格编辑入口供用户修改五个分区。工具构造目标内容，保存层再次检查权限。

同一人格的群聊、私聊共享资料。涉及个人事实时标明对应成员和必要的适用会话。昵称保持一个条目一个昵称或对应关系，黑话含义与详细流程保存在记事本。

## 一轮对话的数据

收到消息后，读取本轮人格的完整五分区资料，提供给回复判断和正式回复。回复判断还接收当前时间及按预算保留的近期聊天副本；正式回复使用完整的最新有效历史。

记事本完整目录和到期的维护提醒放在本轮临时区。与 LCM 配合时，每次模型调用重新读取目录；单独使用时随本轮请求生成。目录不反复写入持久历史。

记事本使用说明随工具定义提供给正式回复模型。回复判断不接收本轮目录、维护提醒、工具说明和参数；历史里已经正常保存的工具调用、返回和已读正文继续参与预算管理。

机器人按目录选择页面，调用读取工具获得正文。工具调用与返回沿 AstrBot 原流程进入历史，已经读过且仍在窗口内的正文可以继续使用。页面变化时，写入前重新读取。

模型接口提供当前资料。管理编号、查询、恢复和存储定位信息留在插件内部与管理页；旧工具记录中的管理字段投影移除时保留原文档案及调用关系。

## 主动维护与提醒计数

机器人可随时调用 nickname_update 增删昵称，或调用 self_memory_update 修改自我认知。两者遵循用户的人设、回复偏好与聊天示例；黑话和详细事实由记事本维护。

默认每个会话、人格组合连续 100 轮未维护时，在第 100 轮正式回复前提供：

> 你已经很久没有更新昵称和自我认知了。看看最近的消息，有没有值得更新的内容；如果有，先更新再回复，没有就正常回复。

计数在回复判断放行后进行，合并消息的一次正式回复算一轮，工具往返及同一消息的重复执行去重。判断后沉默的消息不计数。计数和消息标识持久保存，重启后保留。

提醒加入本轮临时内容后计数清零，随后无论修改或正常回复均重新累计。模型工具成功保存昵称或自我认知的实际变化时，同一人格所有会话的计数清零，因为这些资料由同一人格共享；无变化或失败不清零。用户手动编辑保持当前计数。关闭提醒暂停累计，重新开启继续累计。

与 LCM 配合时，提醒通过临时声明进入当前提供商输入；单独运行时标记为不保存的临时内容。提醒不进入回复判断或持久历史。内容是否值得更新由正在回复的模型依据可见上下文决定。

## 保存与恢复

每次保存先留下原文备份和待提交记录，再使用 AstrBot 原生人格管理器写入、回读；成功后确认记录，模型工具实际修改时原子清零维护计数。插件数据库与人格数据库不假定共用事务，重启通过原文和目标内容恢复待提交记录。

恢复尚未写入的人格变动时，自我认知和昵称工具同样接受权限检查。旧自动整理的待提交结果若尚未写入则标为结束使用；已写入结果与原始记录继续留存。

原生人格编辑入口的正常连续保存分别形成记录。绕过保存入口的数据库修改只能在发现时留存当前状态，不承诺恢复所有中间变化。

用户恢复历史记录默认只恢复昵称和自我认知；同时恢复历史中的人设、回复偏好和聊天示例需要勾选对应选项；勾选后恢复没有示例的旧记录会将示例置空。恢复形成一条新的用户操作记录，提交时检查当前内容是否变化。

## 工具契约

所有工具绑定本轮实际选中的人格，不接受其他人格参数。失败统一返回 ok=false、稳定 error 和 message，保存成功以工具返回为准。

### get_self_prompt

无模型入参。成功返回 ok 和 sections，sections 含 persona、output_preferences、chat_examples、other 四个字符串以及 nicknames 字符串列表。other 作为兼容字段名，内容是自我认知。

### nickname_update

| 参数 | 必填 | 默认行为和含义 |
| --- | --- | --- |
| add | 否 | 要添加的字符串列表，省略表示不添加 |
| remove | 否 | 要移除的完整条目列表，省略表示不移除 |

至少一个参数含非空条目，两者不能包含同一项。条目去首尾空白、去重；删除按完整条目匹配，改名可以同时移除旧项和添加新项。重复添加已有项或删除不存在的条目保持原状。

对最新列表应用增删，连续并发冲突返回 content_changed；超过可维护内容预算返回 memory_budget_exceeded。参数无操作返回 nickname_action_required，类型不合法、空条目或管理标记返回 invalid_nicknames。成功返回 ok 和更新后的完整 nicknames，在管理页记录为“昵称维护”。同轮后续调用与下一轮可读取最新列表。

### self_memory_update

| 参数 | 必填 | 含义 |
| --- | --- | --- |
| content | 是 | 自我认知的完整新正文，空字符串可清空 |

基于本轮常驻内容或最近一次 get_self_prompt 的正文写入。目标部分已变化时返回 content_changed，先重新读取再合并。成功返回 ok、self_knowledge、changed，实际改变才重置计数并保存“自我认知维护”记录。

工具只构造 other 分区的修改，保存层精确检查其他分区、标题及外部附注。正文中的分区标记返回 invalid_section_content，超出昵称与自我认知预算返回 memory_budget_exceeded。昵称、性格和人设、回复偏好及聊天示例保持原文。

### notebook_read

| 参数 | 必填 | 默认行为和含义 |
| --- | --- | --- |
| page_id | 是 | 当前页面标识 |
| offset | 否 | 0，正文字符偏移 |
| limit | 否 | 4000，范围为 1 到 4000 |

返回 ok、page_id、title、description、content、offset、total_chars、next_offset、has_more。通过 next_offset 继续分页；分页期间页面变化时返回 page_changed，页面不存在时返回 page_not_found。

### notebook_create

| 参数 | 必填 | 含义 |
| --- | --- | --- |
| title | 是 | 非空，最多 24 个字符 |
| description | 是 | 非空，最多 60 个字符，说明页面用途和读取时机 |
| content | 是 | 非空完整正文，最多 12,000 个字符 |

成功返回 ok、page_id、title、description、remaining_pages。目录需完整展示，页数或目录字节超额分别返回 notebook_full 或 catalog_budget_exceeded。并发创建的容量检查与保存位于同一事务；同一任务重复提交相同且仍存在的页面时返回已有结果。

### notebook_update

| 参数 | 必填 | 含义 |
| --- | --- | --- |
| page_id | 是 | 当前页面标识 |
| title | 否 | 新名称，省略保留 |
| description | 否 | 新描述，省略保留 |
| content | 否 | 更新后的完整正文，省略保留 |

三个内容字段至少提供一个，长度限制与创建相同。修改前先读取，替换正文前分段读完全文，插件核对本任务读取的内容与当前页面是否一致；变化时重新读取合并。成功返回 ok、page_id、title、description。

### notebook_delete

| 参数 | 必填 | 含义 |
| --- | --- | --- |
| page_id | 是 | 要删除的当前页面 |

删除前读取当前页，内部核对内容。成功返回 ok、page_id、page_count、remaining_pages，释放当前页面容量。满页时仍能读写与删除已有页面，降低页数上限保留所有已有页，直到有空位后允许新建。

## 配置、管理与来源

| 配置键 | 默认值 | 规则 |
| --- | --- | --- |
| memory_reminder_enabled | true | 控制维护提醒及轮次累计 |
| memory_reminder_interval | 100 | 正整数，按连续未维护的回复轮次触发 |
| notebook_max_pages | 100 | 每个人格当前页数上限 |
| long_term_memory_max_bytes | 8000 | 昵称与自我认知的 UTF-8 字节上限 |
| notebook_catalog_max_bytes | 20000 | 完整目录 UTF-8 字节预算，包含名称、描述、标识和结构 |

人设、回复偏好和聊天示例不计入可维护内容预算，仍计入总输入。已有超额内容保留，两个模型工具产生的变化需符合预算。目录预算不允许降到低于当前目录实际大小。

管理页复用 AstrBot 登录和插件扩展 API，提供当前记忆、记事本、记忆记录和配置四个区域。用户能手动编辑五分区、逐项管理昵称、查看字节和进度、管理页面与恢复历史。

成功修改保存完整五分区快照，管理页显示操作类型与结果。旧版整理记录及其原文来源继续可查；新的主动维护依据回复模型已有的上下文，工具记录保留实际提交的正文。管理页定期提示新的工具修改结果，同时保留用户正在编辑的表单。

来源时间保存为 UTC，管理展示遵循配置时区；模型输入转换为本地时间并省略时区后缀。

## 旧数据迁移

| 旧内容 | 新位置或处理 |
| --- | --- |
| 独立固定设定正文 | 原文合入性格和人设，继续仅供用户修改 |
| 原 persona、output_preferences | 分别保留为性格和人设、回复偏好 |
| 旧布局没有聊天示例 | 补入空的 chat_examples 分区，现有正文保留 |
| 原常驻 memory、其他正文 | 原文保留在自我认知，内部 other 字段和定位标记兼容 |
| 已单列的昵称 | 现有列表沿用，文本按非空行转列表并去重 |
| 已有记事本及原文来源 | 原样保留 |
| 旧纯文本人设 | 整体保留在性格和人设 |

升级前备份人格完整原文，保留外部附注，不调用模型重新分类。重复升级保持幂等。混在旧人设或笔记中的称呼保留原文，由用户整理或通过昵称工具维护。

从旧版自动整理升级时，旧队列和来源保留为历史资料，首次启用轮次提醒从零开始；后续升级保留已有计数。旧备份可导入查看并注明导入时间；旧版已缺失的来源不伪造。数据保存于 auto_memory.sqlite3、backups/ 与既有升级备份目录，更新程序文件保留这些私有数据。

## 后续验收与发布

v0.8.0 已完成代码与文档审查，未运行测试或功能验证；v0.7.0 的运行验证也仍待授权。后续获准时，需要在隔离临时库和管理页运行以下场景：

- 旧各类布局的原文保留、固定正文合入人设、旧 memory 转 other、重复迁移及旧笔记保留。
- 旧布局补入空聊天示例，已存示例逐字保留，重复迁移不重复插入；旧管理页省略该字段时保留当前示例。
- self_memory_update 只能改 other；昵称工具只能改 nicknames，不能通过标题、外部附注或恢复路径绕过。
- 回复轮次计数、合并消息与工具往返去重、提醒后清零、成功修改清零、无变化与失败保留计数、重启后继续累计。
- 新工具的并发内容变化、超额预算与中断恢复。
- 管理页五分区显示、示例编辑和清空、昵称增删去重、保存回读和选择性恢复；默认恢复保留当前示例，勾选恢复用户设定后采用记录中的示例。
- 回复判断仍看到完整常驻资料，正式回复保留最新有效窗口，工具说明和目录位置保持约定。

真实模型是否恰当使用工具和维护内容，需要单独获准的真实调用观察。发布继续使用 git、gh 和原共享插件源，版本、下载地址与校验值一并更新；发布状态与运行验证分别报告。
